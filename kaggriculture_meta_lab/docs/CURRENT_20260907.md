## Failure families

Aastik and hybrid both win 64/245 player-tapes, only Aastik wins 10, only hybrid
wins 10, and both lose 161. The hybrid opening therefore does not solve the
dominant failure family. Aastik's strict loss set includes 16 near losses, 42
losses below -10k margin, 39 low-output (<60k) collapses, and 34 high-output
(>100k) losses. These require separate mutations.

Opponent-emitted early wheat activity distinguishes complementary policies:
opponents on B11-only wins average 33.9 wheat bought and 29.1 sold by step 5,
versus 13.0 bought and 8.4 sold on V7-only wins. This is diagnostic association,
not a step-0 selector: the opening decision occurs before opponent action is
observable.
