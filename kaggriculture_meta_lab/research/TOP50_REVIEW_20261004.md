# TOP50/TOP12 review and agent adjustment

The archive on `arena/01a08fb2-riemann` is named TOP50 and contains 13
manifests/teams (the supplied TOP12-style current set plus a root archive
layout). It is a materially harder corpus than the old static TOP7 tapes.

## Main findings from the branch analysis

The branch's `V12_ANALYSIS.md` identifies the live ceiling correctly:

- static V2/V7/V8/V10 tapes are effectively capped around 2,800 rating;
- current leader target is about 3,100;
- top agents are seat-aware and reactive, while static tapes emit identical
  P0/P1 actions for all 719 steps;
- top agents use cows/sheep, fertilizer, strawberry/tomato and early land;
- late liquidation is part of the advantage.

Representative leader profile (Majkel-style):

```text
WHEAT + MELON + STRAWBERRY + CARROT + TOMATO
COW x4, SHEEP x5
NE day 0, SW around day 10
fertilizer generation/sales from about day 11
seat-aware opening
endgame liquidation around day 29
```

The attempted V12 failed because it added animals without the complete
management cycle:

```text
BUY -> BUILD_PASTURE -> PLACE -> FEED -> CARE -> harvest fertilizer/milk
```

This is the correct diagnosis, not evidence that animals themselves are bad.

## Adjustment to our best-agent plan

The old static V7/V16 tape remains the benchmark/control, not the new target.
The next agent is a real-schema V12/V13 reactive prototype with:

1. seat-aware opening based on starting cash/player state;
2. bounded cow/sheep management with explicit FEED and CARE state;
3. strawberry/tomato only after cashflow and labor gates pass;
4. fertilizer placement and sale ledger;
5. endgame liquidation;
6. static V7 fallback whenever a precondition or schema field is missing.

No generic price floor is used. Market decisions are state- and capacity-gated.

## Required benchmark matrix

The new prototype must be tested against:

```text
TOP5, TOP7, TOP10, TOP12, TOP15, TOP30/TOP50
V7/V16 static controls
B21/S16

```

Metrics:

```text
W-L-T
score rate
mean material margin
mean own cash
worst margin
errors/timeouts
P0/P1 action divergence
```

A candidate cannot be promoted from static replay H2H alone. It must pass a
closed-loop local gate and a fresh live transfer test.
