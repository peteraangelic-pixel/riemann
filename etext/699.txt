Is it true that for every $1\leq i<j\leq n/2$ there exists some prime $p\geq i$ such that\[p\mid \textrm{gcd}\left(\binom{n}{i}, \binom{n}{j}\right)?\] #699 : [ErSz78] number theory | binomial coefficients A problem of Erdős and Szekeres. A theorem of Sylvester and Schur says that for any $1\leq i\leq n/2$ there exists some prime $p>i$ which divides $\binom{n}{i}$. GPT 5.6 (prompted by Price) has proved that this is true if $j\leq \frac{3}{2}i$ or $n=2j$. It is easy to prove (see the comments) that there are only finitely many possible $n$ which form a counterexample with any fixed $i<j$. Erdős and Szekeres further conjectured that $p\geq i$ can be improved to $p>i$ except in a few special cases. In particular this fails when $i=2$ and $n$ being some particular powers of $2$. They also found some counterexamples when $i=3$, but only one counterexample when $i\geq 4$:\[\textrm{gcd}\left(\binom{28}{5},\binom{28}{14}\right)=2^3\cdot 3^3\cdot 5.\]This is mentioned in problem B31 of Guy's collection [Gu04] . Written by Thomas Bloom (last edited 27 Aug 2026) This is an exposition of a proof of the conjecture when $j\leq 3i/2$, provided by GPT 5.6 Sol (prompted by Liam Price) in a proof claim . Let $v=V_i(n)$ be the part of $\binom{n}{i}$ supported on primes $\geq i$. This problem is then equivalent to asking whether it is possible for $v$ to be coprime to $\binom{n}{j}$ (for $i<j\leq n/2$). The main input is a result of Ecklund, Eggleton, Erdős, and Selfridge [EEES78] , which proves that (with finitely many explicit exceptions) we have $v> \binom{n}{i}^{1/2}$. The key observation (presumably a cornerstone of the divisibility of binomial coefficients literature, although I haven't looked at this properly) is that since\[\binom{n}{i}\binom{n-i}{j-i}=\binom{n}{j}\binom{j}{i}\]if $d\mid \binom{n}{i}$ is coprime to $\binom{n}{j}$ then $d\mid \binom{j}{i}$. Therefore if $v$ is coprime to $\binom{n}{j}$ then by the above $v\mid \binom{j}{i}=\binom{j}{j-i}$, so using Vandermonde's identity \[v^2 \leq \binom{j}{j-i}^2<\sum_{k} \binom{j}{k}\binom{j}{2(j-i)-k}=\binom{2j}{2(j-i)}.\]Therefore, by the [EEES78] result above, in any supposed counterexample to this problem we have\[\binom{n}{i}< \binom{2j}{2(j-i)}.\]Note that this immediately implies that there are only finitely many possible 'bad $n$' for fixed $i<j$. Furthermore, if $j\leq \frac{3}{2}i$, we have $2(j-i)\leq i<j\leq n/2$ and so\[ \binom{2j}{2(j-i)}\leq \binom{2j}{i}\leq \binom{n}{i},\]a contradiction.
